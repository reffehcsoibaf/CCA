## Como instalar e abrir

O CCA (Claude Code Acessível) é uma janela leve para usar o Claude Code com leitor de tela. Precisa de Windows, de uma conta Claude e do Python.

1. Instale o Python 3.10 ou mais novo (recomendado o 3.13), em python.org. Marque "Add Python to PATH" no instalador.
2. Baixe o arquivo **CCA-{versao}.zip** e extraia numa pasta sua.
3. Abra o `abrir.cmd` dessa pasta. Se faltarem o wxPython e o claude-agent-sdk, ele pergunta se pode instalar (responda S).
4. Na primeira vez, use o menu Conta, Entrar na conta Claude. O login é o oficial da Anthropic; o app nunca vê sua senha.

Quem já usa o CCA se atualiza em Ajuda, Verificar atualizações. O arquivo `CCA-{versao}-atualizacao.zip` é só para o atualizador do app; você não precisa baixá-lo.
