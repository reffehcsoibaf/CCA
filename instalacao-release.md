## Como instalar e abrir

O CCA (Claude Code Acessível) é uma janela leve para usar o Claude Code com leitor de tela. Precisa de Windows, de uma conta Claude e do Python.

1. Instale o Python **3.13** (python.org). Marque "Add Python to PATH" no instalador. Por enquanto o `abrir.cmd` só procura o 3.13.
2. Abra o Prompt de Comando e rode: `python -m pip install wxPython claude-agent-sdk`
3. Baixe o arquivo **CCA-{versao}.zip** e extraia numa pasta sua.
4. Abra o `abrir.cmd` dessa pasta.
5. Na primeira vez, use o menu Conta, Entrar na conta Claude. O login é o oficial da Anthropic; o app nunca vê sua senha.

Quem já usa o CCA se atualiza em Ajuda, Verificar atualizações. O arquivo `CCA-{versao}-atualizacao.zip` é só para o atualizador do app; você não precisa baixá-lo.
